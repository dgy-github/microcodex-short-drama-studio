# Traceability

| Type | Format |
| --- | --- |
| Requirement | `REQ-NNN` |
| UI | `UI-NNN` |
| API | `API-NNN` |
| Database/storage | `DB-NNN` |
| Frontend task | `FE-NNN` |
| Backend/runtime task | `BE-NNN` |
| Test | `TEST-NNN` |

## Definition of Ready

- 验收标准可观察、可测试。
- 已查询现有能力和接口所有者。
- UI、API、事件、存储影响与风险已知。
- smoke tests 已计划。

## Definition of Done

- 需求、设计、契约、代码、测试、证据、文档和项目记忆一致。
- 没有重复业务规则。
- Mock、Rust、sidecar 和真实集成遵循同一契约。
- 适用检查通过，跳过项有记录。
