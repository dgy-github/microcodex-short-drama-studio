# 项目技能结构说明书

本项目的本地技能位于 `.agents/skills/`。每个技能包含：

```text
.agents/skills/<skill-name>/
├── SKILL.md
└── agents/openai.yaml
```

`SKILL.md` 使用 YAML 元数据声明 `name` 和中文 `description`，正文给出步骤、
约束、输出和完成证据。技能正文与显示元数据使用中文，技术标识保留英文。

技能分层：

1. `project-init`：所有开发前置。
2. `guided-product-development`：编排 G0-G7 跨层交付。
3. `project-memory`：写代码前查询、公共接口变化后更新。

功能产物写入 `docs/features/<feature-id>/`、`contracts/` 或项目记忆目录；
不得只在聊天中给出阶段结论。
