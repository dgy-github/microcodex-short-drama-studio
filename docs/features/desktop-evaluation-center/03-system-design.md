# Desktop evaluation center system design

Status: G6 local integration passed

## Ownership

`CAP-005` remains the owner of rubric semantics and deterministic aggregation.
`CAP-008` extends its Tauri facade with evaluation presentation and process
control. The new desktop module is an adapter: it reads versioned eval assets,
uses `story-eval`, calls `story-provider` inside Rust, and stores desktop
execution evidence. It does not redefine scores or online policy.

## Dataset boundary

- `offline-v0.1.0` reads the checked-in `eval-case/v1` split files. A case is
  eligible for story scoring only when a matching immutable baseline package is
  present in a checked-in baseline archive.
- `online-local` projects completed local `story-workflow-result/v1` artifacts
  as production-like evaluation samples. It never feeds runtime outcomes back
  into offline criteria or online policy weights.

## Automatic path

Rust validates the package schema and available case gates before any paid
request. It loads only the Bailian credential from Credential Manager, calls
the configured Qwen route, validates all ten dimension records and span
citations, then delegates floors and verdict aggregation to `story-eval`.
One judge/sample is explicitly `partial_advisory`; it cannot promote anything.

## Human blind path

Rust creates an immutable private assignment record and returns a sanitized
`desktop-blind-assignment/v1`. The UI receives the prompt/constraints, artifact,
rubric questions and allowed spans, but no split, model identity, prior score,
defect key, or source path. Submission creates one `eval-score-record/v1` with
`rater_type=internal_spot_check`; an existing submission is never overwritten.

## Storage

Automatic batches, private assignments, and human score records use atomic
partial-file replacement below `%LOCALAPPDATA%/MicrocodeX/ShortDramaStudio/evaluation`.
IDs are generated by Rust and all caller-provided identifiers are allowlisted.

## Case detail presentation

The Svelte catalog view projects the existing `EvaluationCase` contract at a
larger readable scale. Double-click and the explicit detail button open the
same local dialog without an IPC call or selection mutation. The dialog exposes
only catalog metadata already returned by Rust and supports button, backdrop,
and Escape dismissal.
